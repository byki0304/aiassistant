# aiAssistant brand prompts

The mark is an original teal square with a pale chat bubble. Do not copy Telegram, Google, or Flutter logos.

1. App icon: a 1024 square, background `#0F4C5C`, one rounded pale-green bubble `#EFFDDE` slightly right of center. No letters.
2. Maskable icon: the same bubble inside the center 80 percent, with extra teal padding so a circle crop still shows the bubble.
3. Favicon: the same mark at 32 pixels.
4. Empty state: the bubble alone on `#F4F7F8`, no text inside the image.
5. Error state: the same bubble with a small torn corner, still teal and pale green, no logo.
6. Done state: the bubble with a small check shape drawn as a single stroke.
7. Social preview: wide canvas, teal ground, one bubble, the word aiAssistant set in Noto Sans KR beside it.
